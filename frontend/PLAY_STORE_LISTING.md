# Atomize — Google Play store listing draft

Use this copy in Play Console under **Grow users > Store presence > Store listings**. It describes the functionality currently implemented in the app and does not use testimonials or keyword stuffing.

## App name

Atomize

## Short description

Create, organize, complete, and share task lists with friends.

## Full description

Atomize is a focused task-list app for organizing everyday work and personal goals.

Create tasks, break larger tasks into nested subtasks, and keep track of what is complete. Open any task to manage the items underneath it, update task names when plans change, or remove tasks you no longer need.

Atomize also lets you connect with friends and share selected tasks with them. Use the Friends tab to manage connections, then choose who can access a task. Shared tasks show their sharing status so you can keep personal and collaborative work organized in one place.

Features:

- Create and edit personal tasks
- Organize work with nested subtasks
- Mark tasks and subtasks complete
- Review completed items
- Add and manage friends
- Share selected tasks with friends
- Use light or dark appearance settings

Atomize is designed to keep task management clear, simple, and easy to review.
